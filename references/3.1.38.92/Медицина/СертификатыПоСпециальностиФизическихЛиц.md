# СертификатыПоСпециальностиФизическихЛиц (ЗУП 3.1.38.92, подсистема Медицина)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: обязательна, типовой механизм ожидает таблицу с именем `ВТОсновныеСотрудники`
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление СертификатыПоСпециальностиФизическихЛиц подсистемы «Медицина» — сведения о сертификатах специалистов, выданных медицинским работникам по специальности: дата получения и срок действия, серия и номер бланка, учебное заведение, выдавшее сертификат. Формируется из регистра сведений «СертификатыПоСпециальностиФизическихЛиц» левым соединением с обязательной входной временной таблицей «ВТОсновныеСотрудники» (по физическому лицу), из которой берётся сотрудник; строки сотрудников без сертификатов сохраняются с пустыми сведениями. Используется для контроля наличия и сроков действия сертификатов у медицинских работников.

## Параметры

Параметров нет.

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| ФизическоеЛицо | `ЗНАЧЕНИЕ(Справочник.ФизическиеЛица.ПустаяСсылка)` | Ссылка на справочник «ФизическиеЛица» — физическое лицо — владелец сертификата (измерение регистра сведений). |
| Специальность | `ЗНАЧЕНИЕ(Справочник.КлассификаторСпециальностейПоОбразованию.ПустаяСсылка)` | Ссылка на справочник «КлассификаторСпециальностейПоОбразованию» — специальность, на которую выдан сертификат специалиста. |
| ДатаПолучения | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата получения сертификата специалиста. |
| ДействуетПо | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата окончания срока действия сертификата (до которой сертификат действует). |
| Серия | `ВЫРАЗИТЬ("" КАК СТРОКА(14))` | Строка — серия бланка сертификата специалиста. |
| Номер | `ВЫРАЗИТЬ("" КАК СТРОКА(20))` | Строка — номер бланка сертификата специалиста. |
| УчебноеЗаведение | `ЗНАЧЕНИЕ(Справочник.УчебныеЗаведения.ПустаяСсылка)` | Ссылка на справочник «УчебныеЗаведения» — учебное заведение, выдавшее сертификат специалиста. |
| Сотрудник | `НЕОПРЕДЕЛЕНО` | Ссылка на справочник «Сотрудники» — сотрудник, соответствующий физическому лицу (из входной временной таблицы «ВТОсновныеСотрудники»). |
