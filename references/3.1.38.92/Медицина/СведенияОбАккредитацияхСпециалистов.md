# СведенияОбАккредитацияхСпециалистов (ЗУП 3.1.38.92, подсистема Медицина)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: обязательна, типовой механизм ожидает таблицу с именем `ВТОсновныеСотрудники`
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление СведенияОбАккредитацияхСпециалистов подсистемы «Медицина» — сведения об аккредитации медицинских специалистов по специальности: вид и протокол аккредитационной комиссии, профессиональный стандарт, уровень образования, даты действия аккредитации и свидетельство. Формируется из регистра сведений «СведенияОбАккредитацияхСпециалистов» левым соединением с обязательной входной временной таблицей «ВТОсновныеСотрудники» (по физическому лицу); из неё же берутся сотрудник и должность. Используется для анализа аккредитации специалистов по специальностям.

## Параметры

Параметров нет.
