# РабочиеМестаСотрудников (ЗУП 3.1.38.92, подсистема КадровыйУчет)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: есть

Представление РабочиеМестаСотрудников подсистемы «КадровыйУчет» — периоды работы сотрудников на рабочих местах по кадровой истории: сотрудник, организация, подразделение, должность, должность по штатному расписанию, количество ставок, вид кадрового события, роль сотрудника и служебные сведения записей. Формируется по регистру сведений «КадроваяИсторияСотрудников» с учётом периодов действия договоров гражданско-правового характера и подработок (в зависимости от функциональных опций); каждая запись соответствует периоду работы сотрудника на рабочем месте с детализацией до событий (приём, перевод, увольнение, возвратные события). Ограничивающие параметры Организация и Подразделение необязательны. Требует входной временной таблицы сотрудников с периодами работы.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: Истина — запрос строится с ВЫБРАТЬ РАЗРЕШЕННЫЕ, Ложь (по умолчанию) — без ограничения прав. |
| Организация | Строка | Нет | `&Организация` (выражение) | Ограничивает выборку рабочими местами одной организации. Необязательный, принимает выражение языка запросов (значение по умолчанию &Организация); при пустом значении формируется по всем организациям. |
| Подразделение | Строка | Нет | `&Подразделение` (выражение) | Ограничивает выборку рабочими местами одного подразделения. Необязательный, принимает выражение языка запросов (значение по умолчанию &Подразделение); при пустом значении формируется по всем подразделениям. |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| ДатаНачала | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата начала работы сотрудника на данном рабочем месте. |
| ДатаОкончания | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата окончания работы сотрудника на данном рабочем месте; пустая, если работа по месту продолжается. |
| Год | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — год, к которому относится запись о рабочем месте. |
| Сотрудник | `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)` | Ссылка на справочник «Сотрудники» — сотрудник, занимающий рабочее место; ключевое поле набора. |
| ГоловнаяОрганизация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — головная организация сотрудника по иерархии организаций. |
| ФизическоеЛицо | `ЗНАЧЕНИЕ(Справочник.ФизическиеЛица.ПустаяСсылка)` | Ссылка на справочник «ФизическиеЛица» — физическое лицо сотрудника. |
| Период | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — период кадровой истории, к которому относится запись о рабочем месте. |
| ЭтоВозвратноеСобытие | `ЛОЖЬ` | Булево — признак возвратного (сторнирующего) кадрового события по рабочему месту. |
| ПериодВозвратногоСобытия | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — период возвратного кадрового события, связанного с записью. |
| ПериодЗаписи | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — период регистрации записи о рабочем месте. |
| ДокументОснование | `ЗНАЧЕНИЕ(Документ.КадровыйПеревод.ПустаяСсылка)` | Ссылка на документ кадрового учёта — документ-основание кадрового изменения (приём, перевод и т.п.). |
| РегистраторСобытия | `ЗНАЧЕНИЕ(Документ.КадровыйПеревод.ПустаяСсылка)` | Ссылка на документ кадрового учёта — документ-регистратор кадрового события. |
| РегистраторЗаписи | `ЗНАЧЕНИЕ(Документ.КадровыйПеревод.ПустаяСсылка)` | Ссылка на документ кадрового учёта — документ-регистратор, внесший запись о рабочем месте. |
| ПустойИнтервал | `ЛОЖЬ` | Булево — признак пустого интервала записей о рабочем месте (пропуска в кадровой истории). |
| Организация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — организация, в которой находится рабочее место. |
| Подразделение | `ЗНАЧЕНИЕ(Справочник.ПодразделенияОрганизаций.ПустаяСсылка)` | Ссылка на справочник «ПодразделенияОрганизаций» — подразделение, в котором расположено рабочее место. |
| Должность | `ЗНАЧЕНИЕ(Справочник.Должности.ПустаяСсылка)` | Ссылка на справочник «Должности» — должность сотрудника на рабочем месте. |
| ДолжностьПоШтатномуРасписанию | `ЗНАЧЕНИЕ(Справочник.ШтатноеРасписание.ПустаяСсылка)` | Ссылка на справочник «ШтатноеРасписание» — позиция штатного расписания, соответствующая рабочему месту. |
| ВидСобытия | `ЗНАЧЕНИЕ(Перечисление.ВидыКадровыхСобытий.ПустаяСсылка)` | Ссылка на перечисление «ВидыКадровыхСобытий» — вид кадрового события (приём, перевод, увольнение и т.п.), установившего рабочее место. |
| ГоловнойСотрудник | `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)` | Ссылка на справочник «Сотрудники» — головной сотрудник для совместителя или внутреннего сотрудника, работающего по нескольким позициям. |
| ВидДоговора | `ЗНАЧЕНИЕ(Перечисление.ВидыДоговоровССотрудниками.ПустаяСсылка)` | Ссылка на перечисление «ВидыДоговоровССотрудниками» — вид договора с сотрудником на данном рабочем месте. |
| ЭтоГоловнойСотрудник | `ЛОЖЬ` | Булево — признак того, что сотрудник является головным по данному рабочему месту. |
| КоличествоСтавок | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(22, 20))` | Число (ставки) — количество ставок, которое занимает сотрудник на данном рабочем месте. |
| РольСотрудника | `НЕОПРЕДЕЛЕНО` | Ссылка — роль сотрудника на рабочем месте (например, руководитель); значение определяется по коду регистра сведений кадровой истории. |

## Программный интерфейс

Шаблон кода на встроенном языке; правила подстановки плейсхолдеров `<…>` — в `references/программный-интерфейс.md`.

```bsl
ПараметрыПостроения = КадровыйУчет.ПараметрыДляЗапросВТРабочиеМестаСотрудниковПоВременнойТаблице(
	ИмяВТСотрудникиПериоды = "<Фильтр>",
	ИмяПоляСотрудник = "Сотрудник",
	ИмяПоляНачалоПериода = "НачалоПериода",
	ИмяПоляОкончаниеПериода = "ОкончаниеПериода");

ПараметрыПостроения.Организация = <Организация>;
ПараметрыПостроения.Подразделение = <Подразделение>;

КадровыйУчет.СоздатьВТРабочиеМестаСотрудников(МенеджерВременныхТаблиц,
											   <ТолькоРазрешенные>,
											   ПараметрыПостроения,
											   "ВТРабочиеМестаСотрудников");
```
