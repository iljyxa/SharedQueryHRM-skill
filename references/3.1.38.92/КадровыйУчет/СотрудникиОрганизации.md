# СотрудникиОрганизации (ЗУП 3.1.38.92, подсистема КадровыйУчет)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: не обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: есть

Представление СотрудникиОрганизации подсистемы «КадровыйУчет» — набор кадровых и личных сведений о сотрудниках организации за заданный период. Каждая строка набора содержит дату периода, ссылки на сотрудника и связанное с ним физическое лицо, а также значения запрошенных кадровых данных: рабочее место, условия и оплату труда, график работы, личные данные, стажи, документы и прочие показатели. Набор формируется выбором сотрудников организации (по трудовым договорам, подработкам и договорам гражданско-правового характера) с последующим присоединением значений кадровых данных из регистров сведений на дату периода, равную окончанию периода выборки. Требует указания периода параметрами «НачалоПериода» и «ОкончаниеПериода»; если период не задан, данные формируются на текущую дату сеанса. Назначение — виртуальный источник кадровых данных сотрудников для запросов и отчётов.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: при значении «Истина» текст запроса строится с ключевым словом «РАЗРЕШЕННЫЕ», при «Ложь» (по умолчанию) ограничение по правам снимается. Необязательный, значение не является выражением языка запросов. |
| Организация | Строка | Нет | `&Организация` (выражение) | Ограничивает набор сотрудниками указанной организации; при пустом значении в набор попадают сотрудники всех организаций. При включённом отборе по головной организации по заданному значению определяется головная организация для отбора. Необязательный, принимает выражение языка запросов (значение по умолчанию «&Организация»). |
| Подразделение | Строка | Нет | `&Подразделение` (выражение) | Ограничивает набор сотрудниками указанного подразделения и всех подчинённых ему подразделений (отбор по иерархии); при пустом значении в набор попадают сотрудники всех подразделений. Необязательный, принимает выражение языка запросов (значение по умолчанию «&Подразделение»). |
| ОтбиратьПоГоловнойОрганизации | Булево, Строка | Нет | `ЛОЖЬ` | Определяет порядок отбора по организации: при значении «Истина» отбор выполняется по головной организации, к которой относится заданная организация, при «Ложь» — по текущей организации. Необязательный, по умолчанию «Ложь», значение не является выражением языка запросов. |
| НачалоПериода | Строка | Нет | `&НачалоПериода` (выражение) | Задаёт начальную дату периода, на который формируются кадровые данные сотрудников; при заполнении параметр «ОкончаниеПериода» становится обязательным. При незаполненных границах периода данные формируются на текущую дату сеанса. Необязательный, принимает выражение языка запросов (значение по умолчанию «&НачалоПериода»). |
| ОкончаниеПериода | Строка | Нет | `&ОкончаниеПериода` (выражение) | Задаёт конечную дату периода, на который формируются кадровые данные сотрудников; значение должно быть не ранее «НачалаПериода» и определяет дату поля «Период» результата. Если параметр не заполнен, данные формируются на текущую дату сеанса. Необязательный, принимает выражение языка запросов (значение по умолчанию «&ОкончаниеПериода»). |
