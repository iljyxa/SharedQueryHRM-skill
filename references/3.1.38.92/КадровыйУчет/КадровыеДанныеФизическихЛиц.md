# КадровыеДанныеФизическихЛиц (ЗУП 3.1.38.92, подсистема КадровыйУчет)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: обязательна
- **Отборы по полям**: поддерживаются
- **Программный интерфейс**: есть

Представление КадровыеДанныеФизическихЛиц подсистемы «КадровыйУчет» — расширенный набор личных данных физических лиц без привязки к рабочим местам: ФИО, документы, удостоверяющие личность, контакты и адреса, инвалидность, гражданство, образование, языки, профессии и специальности, стажи, семейное положение, учёные степени и звания. Формируется по регистрам сведений личных данных физического лица за период с учётом таблицы-фильтра и отборов; одна строка — на физическое лицо за период. Используется как виртуальный источник полей в запросах и отчётах СКД, когда сведения о рабочих местах не требуются.
