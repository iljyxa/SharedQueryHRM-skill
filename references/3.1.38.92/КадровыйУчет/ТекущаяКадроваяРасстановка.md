# ТекущаяКадроваяРасстановка (ЗУП 3.1.38.92, подсистема КадровыйУчет)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: есть

Представление ТекущаяКадроваяРасстановка подсистемы «КадровыйУчет» — актуальная на заданную дату расстановка сотрудников по рабочим местам без уволенных. Каждая строка — рабочее место (головная организация, организация, подразделение, должность, должность по штатному расписанию) с присоединёнными из штатного расписания характеристиками (разряд/категория, способ отражения зарплаты в бухучёте, отношение к ЕНВД, статья финансирования) и суммарным количеством ставок занятых на нём сотрудников. Строится по срезу последних регистра сведений «КадроваяИсторияСотрудников» на дату с последующей группировкой по рабочему месту. Требует обязательного параметра Дата; параметр Организация при заполнении ограничивает выборку одной организацией.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: Истина — запрос строится с ВЫБРАТЬ РАЗРЕШЕННЫЕ, Ложь (по умолчанию) — без ограничения прав. |
| Дата | Строка | Да | `&Дата` (выражение) | Задаёт дату, на которую формируется расстановка (дата среза кадровой истории). Обязательный, принимает выражение языка запросов (значение по умолчанию &Дата). |
| Организация | Строка | Нет | `&Организация` (выражение) | Ограничивает расстановку одной организацией: при заполнении отбираются рабочие места только этой организации, от неё же строится отбор по головной организации. Необязательный, принимает выражение языка запросов (значение по умолчанию &Организация); при пустом значении формируется по всем организациям. |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| ГоловнаяОрганизация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — головная организация, к которой относится рабочее место по иерархии организаций. |
| Организация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — организация, в которой находится рабочее место. |
| Подразделение | `ЗНАЧЕНИЕ(Справочник.ПодразделенияОрганизаций.ПустаяСсылка)` | Ссылка на справочник «ПодразделенияОрганизаций» — подразделение организации, в котором расположено рабочее место. |
| Должность | `ЗНАЧЕНИЕ(Справочник.Должности.ПустаяСсылка)` | Ссылка на справочник «Должности» — должность, по которой занято рабочее место. |
| ДолжностьПоШтатномуРасписанию | `ЗНАЧЕНИЕ(Справочник.ШтатноеРасписание.ПустаяСсылка)` | Ссылка на справочник «ШтатноеРасписание» — позиция штатного расписания, соответствующая рабочему месту; по ней присоединяются свойства штатной единицы. |
| РазрядКатегория | `ЗНАЧЕНИЕ(Справочник.РазрядыКатегорииДолжностей.ПустаяСсылка)` | Ссылка на справочник «РазрядыКатегорииДолжностей» — разряд или категория должности из позиции штатного расписания. |
| СпособОтраженияЗарплатыВБухучете | `ЗНАЧЕНИЕ(Справочник.СпособыОтраженияЗарплатыВБухУчете.ПустаяСсылка)` | Ссылка на справочник «СпособыОтраженияЗарплатыВБухУчете» — способ отражения заработной платы в бухгалтерском учёте по позиции штатного расписания. |
| ОтношениеКЕНВД | `ЗНАЧЕНИЕ(Перечисление.ОтношениеКЕНВДЗатратНаЗарплату.ПустаяСсылка)` | Ссылка на перечисление «ОтношениеКЕНВДЗатратНаЗарплату» — отношение затрат на оплату труда по рабочему месту к деятельности, облагаемой ЕНВД. |
| СтатьяФинансирования | `ЗНАЧЕНИЕ(Справочник.СтатьиФинансированияЗарплата.ПустаяСсылка)` | Ссылка на справочник «СтатьиФинансированияЗарплата» — статья финансирования расходов на оплату труда по позиции штатного расписания. |
| КоличествоСтавок | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(22, 20))` | Число (ставки) — суммарное количество ставок всех сотрудников, занимающих данное рабочее место; результат агрегации СУММА по срезу кадровой истории. |
