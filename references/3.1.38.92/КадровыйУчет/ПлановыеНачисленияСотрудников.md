# ПлановыеНачисленияСотрудников (ЗУП 3.1.38.92, подсистема КадровыйУчет)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление ПлановыеНачисленияСотрудников подсистемы «КадровыйУчет» — плановые (назначенные на длительный срок) начисления сотрудников за период: вид начисления, размер и документ-основание, а также основной показатель начисления и его значение. Формируется как срез последних записей регистра сведений «ПлановыеНачисления» по сотрудникам и периодам входной временной таблицы-фильтра с присоединением среза значений периодических показателей расчёта зарплаты и вклада в плановый ФОТ: при ведении планового ФОТ размер берётся из регистра «ПлановыйФОТ» (вклад в ФОТ), иначе — из регистра «ПлановыеНачисления». Одна запись — на сотрудника и вид начисления за период; без прав на данные для начисления зарплаты возвращается пустой набор. Требует обязательной временной таблицы-фильтра с полями Сотрудник и Период.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: Истина — запрос строится с ВЫБРАТЬ РАЗРЕШЕННЫЕ, Ложь (по умолчанию) — без ограничения прав. |
| ФормироватьСПериодичностьДень | Булево, Строка | Нет | `ИСТИНА` | Булево (по умолчанию Истина) — управляет точностью построения срезов регистров: при Истина периоды кратности менее суток приводятся к дню (данные унифицируются до дней), при Ложь сохраняется исходная точность (секунды). Влияет на срезы регистров «ПлановыеНачисления», «ЗначенияПериодическихПоказателейРасчетаЗарплатыСотрудников» и «ПлановыйФОТ». |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| Период | `НЕОПРЕДЕЛЕНО` | Дата — месяц (первый день месяца), к которому относится плановое начисление; период среза по сотруднику. |
| ПериодЗаписи | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — период (дата) последней регистрации записей показателей, участвующих в расчёте начисления. |
| Регистратор | `ЗНАЧЕНИЕ(Документ.НазначениеПлановогоНачисления.ПустаяСсылка)` | Ссылка на документ «НазначениеПлановогоНачисления» — документ, установивший плановое начисление (регистратор записи регистра сведений). |
| Сотрудник | `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)` | Ссылка на справочник «Сотрудники» — сотрудник, которому назначено плановое начисление; ключевое поле набора (измерение регистра). |
| Начисление | `ЗНАЧЕНИЕ(ПланВидовРасчета.Начисления.ПустаяСсылка)` | Ссылка на план видов расчёта «Начисления» — вид планового начисления (настройка начисления, оклад и т.п.). |
| ДокументОснование | `ЗНАЧЕНИЕ(Документ.НазначениеПлановогоНачисления.ПустаяСсылка)` | Ссылка на документ «НазначениеПлановогоНачисления» — документ-основание, по которому установлено начисление. |
| Размер | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(15, 2))` | Число (руб.) — размер (сумма) планового начисления за период: вклад в плановый ФОТ из регистра «ПлановыйФОТ» (при его ведении), иначе — размер из регистра сведений «ПлановыеНачисления». |
| ОсновнойПоказатель | `ЗНАЧЕНИЕ(Справочник.ПоказателиРасчетаЗарплаты.ПустаяСсылка)` | Ссылка на справочник «ПоказателиРасчетаЗарплаты» — основной показатель вида начисления (первая строка состава показателей, помеченная основным); пустая ссылка, если показатель не задан. |
| ЗначениеОсновногоПоказателя | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(15, 5))` | Число — значение основного показателя начисления за период по срезу последних регистра «ЗначенияПериодическихПоказателейРасчетаЗарплатыСотрудников»; 0, если значение не введено. |
| НачислениеТарифнойСтавки | `ЛОЖЬ` | Булево — признак того, что начисление является начислением по тарифной ставке (оклад, тарифная ставка); используется при отборе основных начислений вместо суммирования. |
