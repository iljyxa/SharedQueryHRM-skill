# СтажиСотрудников (ЗУП 3.1.38.92, подсистема КадровыйУчет)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: есть

Представление СтажиСотрудников подсистемы «КадровыйУчет» — набор сведений о стажах физических лиц по видам стажа. Каждая строка набора соответствует записи о стаже: период, на который рассчитывается стаж, физическое лицо и вид стажа, даты начала и окончания периода стажа, зафиксированный размер в месяцах и днях и признак прерывания стажа. Для каждой записи рассчитывается общая продолжительность стажа на дату расчёта с разложением на полные годы, месяцы и дни. Источником отборов служит первая входная временная таблица с полями «ФизическоеЛицо» и «Период», определяющими дату расчёта стажа. Назначение — предоставление данных о стажах физических лиц для запросов и отчётов.

## Параметры

Параметров нет.

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| ПериодРегистрации | `НЕОПРЕДЕЛЕНО` | Дата — период регистрации записи о стаже физического лица; равен дате расчёта стажа (периоду из таблицы отборов). |
| Период | `НЕОПРЕДЕЛЕНО` | Дата — период, на который рассчитывается стаж; значение берётся из таблицы отборов физических лиц и совпадает с датой расчёта стажа. |
| ДатаРасчетаСтажа | `НЕОПРЕДЕЛЕНО` | Дата — дата, на которую рассчитан стаж физического лица. Определяется полем «Период» таблицы отборов и одинакова для всех записей набора. |
| ФизическоеЛицо | `ЗНАЧЕНИЕ(Справочник.ФизическиеЛица.ПустаяСсылка)` | Ссылка на справочник «ФизическиеЛица» — физическое лицо, по которому рассчитан стаж; по нему объединяются данные о стажах из регистра сведений. |
| ВидСтажа | `ЗНАЧЕНИЕ(Справочник.ВидыСтажа.ПустаяСсылка)` | Ссылка на справочник «ВидыСтажа» — вид стажа (общий, непрерывный, страховой, северный и т.п.), к которому относится запись. |
| ДатаОтсчета | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата начала периода стажа, от которой ведётся отсчёт его длительности; не может быть ранее 01.01.1900. |
| ДатаОкончания | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата окончания периода стажа; для стажа, действующего на дату расчёта, может быть пустой датой. |
| РазмерМесяцев | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(3, 0))` | Число (месяцы) — зафиксированный в записи регистра размер стажа в месяцах на дату отсчёта; учитывается при расчёте общей длительности стажа. |
| РазмерДней | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(2, 0))` | Число (дни) — зафиксированный в записи регистра размер стажа в днях на дату отсчёта; учитывается при расчёте общей длительности стажа. |
| Прерван | `ЛОЖЬ` | Булево — признак того, что период стажа прерван; для прерванного стажа его длительность не увеличивается со временем. |
| ВсегоМесяцев | `0` | Число (полные месяцы) — общая длительность стажа в месяцах на дату расчёта: сумма зафиксированного размера и месяцев, прошедших с даты отсчёта. |
| Лет | `0` | Число (полные годы) — количество полных лет стажа, выделенное из общей длительности стажа на дату расчёта. |
| Месяцев | `0` | Число (полные месяцы) — количество полных месяцев стажа в остатке после выделения полных лет; вместе с полями «Лет» и «Дней» раскладывает общую длительность стажа. |
| Дней | `0` | Число (полные дни) — количество дней стажа в остатке после выделения полных лет и месяцев; вместе с полями «Лет» и «Месяцев» раскладывает общую длительность стажа. |
| НачалоБудущегоМесяца | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — служебная дата начала месяца, следующего за датой расчёта стажа; используется при расчёте длительности стажа. |
