# ПлановыеУдержанияСотрудников (ЗУП 3.1.38.92, подсистема КадровыйУчет)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление ПлановыеУдержанияСотрудников подсистемы «КадровыйУчет» — плановые удержания сотрудников за период: вид удержания, сумма (значение) удержания и предел, получатель-контрагент. Формируется по регистру сведений «ПлановыеУдержания» (на начало периода) с присоединением значений периодических показателей удержаний, условий удержаний по исполнительным документам (сумма или процент и предел) и получателей удержаний; сотрудник определяется по текущим кадровым данным, период ограничивается приёмом и увольнением. Сумма удержания выбирается из: значения основного показателя (если введено), иначе условия по исполнительному документу (сумма или процент), иначе размера регистра. Требует обязательной временной таблицы-фильтра с полями Сотрудник, ДатаНачала и ДатаОкончания.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: Истина — запрос строится с ВЫБРАТЬ РАЗРЕШЕННЫЕ, Ложь (по умолчанию) — без ограничения прав. |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| Период | `НЕОПРЕДЕЛЕНО` | Дата — период, к которому относится плановое удержание (принимает дату окончания интервала отбора). |
| ФизическоеЛицо | `ЗНАЧЕНИЕ(Справочник.ФизическиеЛица.ПустаяСсылка)` | Ссылка на справочник «ФизическиеЛица» — физическое лицо, по которому производится удержание (измерение регистра сведений). |
| Сотрудник | `НЕОПРЕДЕЛЕНО` | Ссылка на справочник «Сотрудники» — сотрудник, по которому производится удержание; определяется по текущим кадровым данным на период. |
| Регистратор | `ЗНАЧЕНИЕ(Документ.ПрикреплениеКПрограммамМедицинскогоСтрахования.ПустаяСсылка)` | Ссылка на документ — документ-регистратор записи планового удержания (например «НазначениеПлановогоУдержания», «ИсполнительныйДокумент»); композитный тип по регистру. |
| Организация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — организация, где осуществляется удержание. |
| ФизическоеЛицо1 | `ЗНАЧЕНИЕ(Справочник.ФизическиеЛица.ПустаяСсылка)` | Ссылка на справочник «ФизическиеЛица» — вспомогательное поле, дублирующее физическое лицо (по второму измерению регистра); используется построителем для внутренних связок, при конструировании запросов обычно не требуется. |
| Удержание | `ЗНАЧЕНИЕ(ПланВидовРасчета.Удержания.ПустаяСсылка)` | Ссылка на план видов расчёта «Удержания» — вид планового удержания (алименты, профсоюзные взносы и т.п.). |
| ДокументОснование | `ЗНАЧЕНИЕ(Документ.ПрикреплениеКПрограммамМедицинскогоСтрахования.ПустаяСсылка)` | Ссылка на документ — документ-основание установления удержания (например «ИсполнительныйДокумент», «ДоговорКредита»); композитный тип по регистру. |
| ОсновнойПоказатель | `ЗНАЧЕНИЕ(Справочник.ПоказателиРасчетаЗарплаты.ПустаяСсылка)` | Ссылка на справочник «ПоказателиРасчетаЗарплаты» — основной показатель удержания (из состава показателей вида удержания); пустая ссылка, если показатель не задан. |
| Контрагент | `ЗНАЧЕНИЕ(Справочник.Контрагенты.ПустаяСсылка)` | Ссылка на справочник «Контрагенты» — получатель удержания (получатель алиментов, кредитор и т.п.); берётся из регистра сведений «ПолучателиУдержаний». |
| Значение | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(18, 5))` | Число — сумма удержания за период: значение основного показателя (если введено), иначе сумма или процент условия по исполнительному документу, иначе размер из регистра «ПлановыеУдержания». |
| Предел | `0` | Число — предельная сумма удержания, свыше которой удержание не производится (из условий по исполнительному документу); 0 — предел не установлен. |
