# ОтработанноеВремя (ЗУП 3.1.38.92, подсистема УчетНачисленнойЗарплаты)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление ОтработанноеВремя подсистемы «УчетНачисленнойЗарплаты» — отработанное и оплаченное время сотрудников по данным регистра накопления «ОтработанноеВремяПоСотрудникам» с учётом корректировочных записей регистра «ОтработанноеВремяПоСотрудникамКорректировка». Строка набора: месяц начисления, период действия, сотрудник, организация, подразделение, вид расчёта, документ-основание, дата начала и значения отработанных/оплаченных дней и часов (в периоде начисления и суммарно). Требует обязательных границ интервала НачалоПериода и ОкончаниеПериода, а также входной временной таблицы начислений и удержаний, из которой по связке строки присоединяются статья финансирования и статья расходов. Используется в общих запросах расчёта начислений и анализа отработанного времени.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| НачалоПериода | Строка, Дата | Да | `&НачалоПериода` (выражение) | Задаёт начальную дату интервала, за который формируется отработанное время. Обязательный, принимает дату или выражение языка запросов (значение по умолчанию &НачалоПериода). |
| ОкончаниеПериода | Строка, Дата | Да | `&ОкончаниеПериода` (выражение) | Задаёт конечную дату интервала, за который формируется отработанное время. Обязательный, принимает дату или выражение языка запросов (значение по умолчанию &ОкончаниеПериода). |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| МесяцНачисления | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — месяц начисления (начало месяца периода записи отработанного времени). |
| ПериодДействия | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — период действия отработанного времени (месяц, к которому относится время; может отличаться от месяца начисления при переносе времени). |
| Регистратор | `ЗНАЧЕНИЕ(Документ.СторнированиеНачислений.ПустаяСсылка)` | Ссылка на документ — документ-регистратор записи отработанного времени. |
| Сотрудник | `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)` | Ссылка на справочник «Сотрудники» — сотрудник, по которому учтено отработанное время. |
| Организация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — организация сотрудника. |
| Подразделение | `ЗНАЧЕНИЕ(Справочник.ПодразделенияОрганизаций.ПустаяСсылка)` | Ссылка на справочник «ПодразделенияОрганизаций» — подразделение, по которому учтено отработанное время. |
| ВидРасчета | `ЗНАЧЕНИЕ(ПланВидовРасчета.Начисления.ПустаяСсылка)` | Ссылка на план видов расчёта «Начисления» — вид расчёта (начисление), по которому учтено отработанное время. |
| ДокументОснование | `ЗНАЧЕНИЕ(Документ.НазначениеПлановогоНачисления.ПустаяСсылка)` | Ссылка на документ — документ-основание записи отработанного времени (например назначение планового начисления). |
| ДатаНачала | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата начала периода действия начисления или отработанного времени. |
| ВремяВЧасах | `ЛОЖЬ` | Булево — признак учёта отработанного времени в часах (Истина) либо в днях (Ложь). |
| ИдентификаторСтроки | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(7, 0))` | Число — идентификатор строки записи регистратора, служащий для связки со строками табличной части начислений и удержаний. |
| ОтработаноДней | `0` | Число (дни) — суммарное количество отработанных дней по записи (включая время, отнесённое на другие периоды). |
| ОтработаноЧасов | `0` | Число (часы) — суммарное количество отработанных часов по записи. |
| ОтработаноДнейВПериоде | `0` | Число (дни) — количество отработанных дней, отнесённых в сам период начисления (без перенесённого на другие периоды). |
| ОтработаноЧасовВПериоде | `0` | Число (часы) — количество отработанных часов, отнесённых в сам период начисления. |
| ОплаченоДней | `0` | Число (дни) — суммарное количество оплаченных дней по записи. |
| ОплаченоЧасов | `0` | Число (часы) — суммарное количество оплаченных часов по записи. |
| СтатьяФинансирования | `НЕОПРЕДЕЛЕНО` | Ссылка на справочник «СтатьиФинансированияЗарплата» — статья финансирования, присоединяемая из входной таблицы начислений и удержаний по связке строки. |
| СтатьяРасходов | `НЕОПРЕДЕЛЕНО` | Ссылка — статья расходов, присоединяемая из входной таблицы начислений и удержаний по связке строки (композитный тип по коду строки начислений). |
