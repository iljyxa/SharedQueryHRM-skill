# НачисленныеДоходыНДФЛ (ЗУП 3.1.38.92, подсистема УчетНачисленнойЗарплаты)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление НачисленныеДоходыНДФЛ подсистемы «УчетНачисленнойЗарплаты» — начисленные физическим лицам доходы для отчётов по НДФЛ: сумма за месяц по виду дохода, документ-основание и признак обложения НДФЛ. Строится объединением записей регистров накопления «НачисленияУдержанияПоСотрудникам», «НачисленияУдержанияПоСотрудникамАвансом» и «НачисленияУдержанияПоКонтрагентамАкционерам» (группы «Начислено», «Льготы», «Справочно», кроме зачтённого НДФЛ), отобранных по физическим лицам и периодам входной временной таблицы. Признак ОблагаетсяНДФЛ вычисляется по коду дохода НДФЛ вида начисления (пустой код — не облагается) и перечню освобождаемых особых начислений; обложение компенсации за задержку зарплаты зависит от функциональной опции «СчитатьКомпенсациюЗаЗадержкуЗарплатыОблагаемымНДФЛДоходом». Требует входной временной таблицы периодов доходов по физическим лицам.

## Параметры

Параметров нет.

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| МесяцНачисления | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — месяц начисления дохода (начало месяца периода записи регистра). |
| Организация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — головная организация начисления (через реквизит «ГоловнаяОрганизация» организации регистратора). |
| ФизическоеЛицо | `ЗНАЧЕНИЕ(Справочник.ФизическиеЛица.ПустаяСсылка)` | Ссылка на справочник «ФизическиеЛица» — физическое лицо, которому начислен доход. |
| ДокументОснование | `ЗНАЧЕНИЕ(Документ.СторнированиеНачислений.ПустаяСсылка)` | Ссылка на документ — документ-регистратор начисления, служащий основанием дохода. |
| Начисление | `ЗНАЧЕНИЕ(Справочник.ВидыВыплатБывшимСотрудникам.ПустаяСсылка)` | Ссылка (композитный тип) — вид начисления или дохода: начисление плана видов расчёта «Начисления», вид выплаты бывшим сотрудникам либо прочий доход физического лица, особое начисление или удержание. |
| Начислено | `0` | Число (руб.) — сумма начисленного дохода; по записям авансовых начислений принимает значение 0. |
| Регистратор | `ЗНАЧЕНИЕ(Документ.СторнированиеНачислений.ПустаяСсылка)` | Ссылка на документ — документ-регистратор записи начислений и удержаний. |
| ОблагаетсяНДФЛ | `ЛОЖЬ` | Булево — признак обложения дохода НДФЛ: Ложь, если виду дохода не задан код дохода НДФЛ или он входит в перечень освобождаемых особых начислений (компенсация за задержку зарплаты, пособия и т.п.). |
