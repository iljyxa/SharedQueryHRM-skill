# Периоды (ЗУП 3.1.38.92, подсистема Общие)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: есть

Представление Периоды подсистемы «Базовые» — формирует временную таблицу с одной колонкой Период: последовательность дат от НачалоИнтервала до ОкончаниеИнтервала с шагом в заданную периодичность (ГОД, КВАРТАЛ, МЕСЯЦ, ДЕНЬ). По умолчанию возвращаются начала периодов, при ИспользоватьКонецПериода = Истина — концы периодов. Используется для построения сетки периодов в запросах и отчётах СКД при группировке и сопоставлении данных по периодам. Источников данных и отборов не требует; границы интервала задаются параметрами и могут быть выражениями языка запросов.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| НачалоИнтервала | Строка, Дата | Да | `&НачалоПериода` (выражение) | Задаёт нижнюю границу интервала, с которой формируется сетка периодов. Обязательный, принимает дату или выражение языка запросов (значение по умолчанию &НачалоПериода). Пустая дата трактуется как 01.01.1980. |
| ОкончаниеИнтервала | Строка, Дата | Да | `&ОкончаниеПериода` (выражение) | Задаёт верхнюю границу интервала, по которую формируется сетка периодов. Обязательный, принимает дату или выражение языка запросов (значение по умолчанию &ОкончаниеПериода). Пустая дата заменяется горизонтом в 60 месяцев от текущей даты сеанса. |
| Периодичность | Строка | Нет | `"МЕСЯЦ"`; допустимые: `ГОД`, `КВАРТАЛ`, `МЕСЯЦ`, `ДЕНЬ` | Определяет шаг сетки периодов: ГОД, КВАРТАЛ, МЕСЯЦ или ДЕНЬ. Необязательный, по умолчанию МЕСЯЦ; любое другое значение приводит к ошибке формирования запроса. |
| ИспользоватьКонецПериода | Булево, Строка | Нет | `ЛОЖЬ` | Определяет, что возвращается в поле Период: Ложь — начало периода (по умолчанию), Истина — конец периода. Необязательный. |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| Период | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — период (начало или конец в зависимости от параметра ИспользоватьКонецПериода) внутри диапазона от НачалоИнтервала до ОкончаниеИнтервала с шагом Периодичности. Одна запись на каждый период; при периодичности «День» дата совпадает с днём интервала. |

## Заготовка текста представления

```bsl
ВЫБРАТЬ
	ДАТАВРЕМЯ(1, 1, 1) КАК Период
ПОМЕСТИТЬ Представления_Периоды
ГДЕ
	"НачалоИнтервала" = &НачалоПериода
	И "ОкончаниеИнтервала" = &ОкончаниеПериода
```

## Программный интерфейс

Шаблон кода на встроенном языке; правила подстановки плейсхолдеров `<…>` — в `references/программный-интерфейс.md`.

```bsl
ЗарплатаКадрыОбщиеНаборыДанных.СоздатьВТПериоды(
	МенеджерВременныхТаблиц,
	<НачалоИнтервала>,
	<ОкончаниеИнтервала>,
	"<Периодичность>",
	"ВТПериоды",
	<ИспользоватьКонецПериода>);
```
