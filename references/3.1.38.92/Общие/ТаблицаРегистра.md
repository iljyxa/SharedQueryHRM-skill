# ТаблицаРегистра (ЗУП 3.1.38.92, подсистема Общие)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: обязательна
- **Источник данных**: требуется регистр сведений — его имя добавляется к имени временной таблицы: `Представления_ТаблицаРегистра_<ИмяРегистра>`; состав полей определяется измерениями, ресурсами и реквизитами регистра
- **Отборы по полям**: поддерживаются
- **Программный интерфейс**: есть

Представление ТаблицаРегистра подсистемы «Базовые» — универсальная выборка основной таблицы (таблицы записей) произвольного периодического регистра сведений. Имя регистра задаётся в имени представления как постфикс после второго подчёркивания: Представления_ТаблицаРегистра_<ИмяРегистра>. Возвращает фактические записи регистра без построения срезов: по каждой записи, попадающей в период таблицы-фильтра, с учётом отборов и опции включения записей на начало периода. Набор полей не фиксирован: состав определяется динамически из метаданных регистра — измерения, ресурсы и реквизиты. Требует входной временной таблицы-фильтра с колонками «ДатаНачала» и «ДатаОкончания» (границы периода записей) и измерениями регистра, по которым устанавливается отбор. Дополнительные отборы по полям набора задаются параметрами вида ЛевоеЗначениеN, ВидСравненияN, ПравоеЗначениеN (тройкой параметров).

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: Истина — запрос строится с ВЫБРАТЬ РАЗРЕШЕННЫЕ, Ложь (по умолчанию) — без ограничения прав. |
| ПсевдонимыПолейСКД | Строка | Нет | `""` | Задаёт переименование полей результата для корректного сопоставления с полями схемы компоновки данных: строка вида «Поле1 КАК Псевдоним1, Поле2 КАК Псевдоним2» через запятую. Необязательный, по умолчанию пусто. |
| ПараметрыПостроения_ФормироватьСПериодичностьДень | Булево, Строка | Нет | `ИСТИНА` | Управляет точностью формирования для регистров с периодичностью «Секунда»: Истина (по умолчанию) — данные приводятся к посуточной кратности (шаг «ДЕНЬ»), Ложь — сохраняется посекундная точность. Для регистров с иной периодичностью не влияет. |
| ПараметрыПостроения_ВключатьЗаписиНаНачалоПериода | Булево, Строка | Нет | `ЛОЖЬ` | Определяет включение записей, действующих на начало периода фильтра: Истина — в результат попадают значения по измерениям фильтра на начало периода (для регистров с периодичностью Секунда, День, Месяц, Квартал, Год), Ложь (по умолчанию) — только записи внутри заданных границ. |

## Поля

Список полей не фиксирован: это измерения, ресурсы и реквизиты выбранного регистра (плюс `Период`, `ДатаНачала`/`ДатаОкончания` в зависимости от представления). Выражение пустого значения подбирается по типу поля регистра, см. «Поля» в `references/механизм-представлений.md`.

## Заготовка текста представления

```bsl
ВЫБРАТЬ
	<ВыражениеПустогоЗначения> КАК <ИмяПоляРегистра>  // измерения, ресурсы, реквизиты регистра
ПОМЕСТИТЬ Представления_ТаблицаРегистра_<ИмяРегистра>
ИЗ
	ВТФильтр КАК ВТФильтр
```

## Программный интерфейс

Шаблон кода на встроенном языке; правила подстановки плейсхолдеров `<…>` — в `references/программный-интерфейс.md`.

```bsl
ОписаниеФильтра = ЗарплатаКадрыОбщиеНаборыДанных.ОписаниеФильтраДляСоздатьВТИмяРегистра(
	"<Фильтр>", <ИзмеренияФильтра>);

ПараметрыПостроения = ЗарплатаКадрыОбщиеНаборыДанных.ПараметрыПостроенияДляСоздатьВТИмяРегистра();
ПараметрыПостроения.ФормироватьСПериодичностьДень = <ПараметрыПостроения_ФормироватьСПериодичностьДень>;
ПараметрыПостроения.ВключатьЗаписиНаНачалоПериода = <ПараметрыПостроения_ВключатьЗаписиНаНачалоПериода>;
<Отборы>
<ПсевдонимыПолейСКД>

ЗарплатаКадрыОбщиеНаборыДанных.СоздатьВТИмяРегистра(
	"<ИмяРегистра>",
	МенеджерВременныхТаблиц,
	<ТолькоРазрешенные>,
	ОписаниеФильтра,
	ПараметрыПостроения,
	"ВТ<ИмяРегистра>");
```
