# ПлановоеВремя (ЗУП 3.1.38.92, подсистема УчетРабочегоВремени)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Плановое рабочее время сотрудников подсистемы «УчетРабочегоВремени»: по сотруднику, месяцу и дате — плановые и нормативные дни и часы по видам использования рабочего времени, смена и её переходящие части, территория выполнения работ и условия труда, признаки плановой строки и агрегации за период. Данные формируются по цепочке: месяцы интервала ДатаНачала–ДатаОкончания → комбинации сотрудник-месяц → плановые данные учёта времени по видам времени. Источники: регистр накопления «ДанныеИндивидуальныхГрафиковСотрудников» (индивидуальные графики), регистр сведений «ГрафикиРаботыПоВидамВремени» (данные общих графиков, график нормы и рассчитанные плановые показатели по видам времени); назначенные графики берутся срезом последних из регистра сведений «ГрафикРаботыСотрудников» на дату актуальности. Строки возвращаются посуточно, агрегированные за период плановые показатели помечаются признаком ВЦеломЗаПериод. Требует входную временную таблицу сотрудников.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Определяет применение отбора РАЗРЕШЕННЫЕ в запросах представления: при Истина в результат попадают только записи, доступные пользователю по правам. По умолчанию Ложь, параметр необязательный. |
| ДатаНачала | Строка, Дата | Да | `&ДатаНачала` (выражение) | Задаёт начальную дату интервала, за который формируется плановое время; по ней определяется первый месяц расчётного периода. Обязательный параметр, принимает выражение языка запросов; по умолчанию &ДатаНачала. |
| ДатаОкончания | Строка, Дата | Да | `&ДатаОкончания` (выражение) | Задаёт конечную дату интервала, за который формируется плановое время; по ней определяется последний месяц расчётного периода. Обязательный параметр, принимает выражение языка запросов; по умолчанию &ДатаОкончания. |
| ДатаАктуальности | Строка, Дата | Да | `&ДатаАктуальности` (выражение) | Определяет дату, на которую актуализируются плановые показатели: по ней берётся срез последних регистра сведений «ГрафикРаботыСотрудников» и отбираются записи, зарегистрированные не позднее этой даты. Обязательный параметр, принимает выражение языка запросов; по умолчанию &ДатаАктуальности. |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| Сотрудник | `НЕОПРЕДЕЛЕНО` | Ссылка на справочник «Сотрудники» — сотрудник, плановое время которого приведено в строке. Состав сотрудников задаётся входной временной таблицей. |
| Месяц | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — месяц расчётного периода, к которому относится плановое время строки (начало месяца). Месяцы формируются по интервалу ДатаНачала–ДатаОкончания. |
| ДатаАктуальности | `НЕОПРЕДЕЛЕНО` | Дата — дата, на которую актуализированы плановые показатели строки. Соответствует параметру ДатаАктуальности; по ней выполняются срезы графиков и отбор записей по периоду регистрации. |
| ПериодРегистрации | `НЕОПРЕДЕЛЕНО` | Дата — период регистрации плановых данных: месяц, в котором зарегистрированы соответствующие данные учёта времени (графика). |
| План | `ЛОЖЬ` | Булево — признак плановых данных: Истина для строк планового времени по видам использования рабочего времени, Ложь — для фактических данных учёта времени, если они включены в формирование. |
| ВЦеломЗаПериод | `ЛОЖЬ` | Булево — признак агрегации за период: Истина, если плановые значения приведены за период целиком и не разбиты по дням, Ложь — для посуточных строк. |
| Дата | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — календарный день, к которому относится плановое время строки. Для строк, агрегированных за период целиком, указывает сам период. |
| ВидУчетаВремени | `ЗНАЧЕНИЕ(Справочник.ВидыИспользованияРабочегоВремени.ПустаяСсылка)` | Ссылка на справочник «ВидыИспользованияРабочегоВремени» — вид использования рабочего времени, по которому планируется время (рабочее время, ночные часы и другие). |
| Территория | `ЗНАЧЕНИЕ(Справочник.ТерриторииВыполненияРабот.ПустаяСсылка)` | Ссылка на справочник «ТерриторииВыполненияРабот» — территория выполнения работ, к которой относится плановое время строки. Заполняется из данных графиков; при отсутствии — пустая ссылка. |
| УсловияТруда | `ЗНАЧЕНИЕ(Справочник.УсловияТруда.ПустаяСсылка)` | Ссылка на справочник «УсловияТруда» — условия труда планового времени, зарегистрированные в данных графиков. При отсутствии — пустая ссылка. |
| ЗарегистрированнаяТерритория | `ЛОЖЬ` | Булево — признак того, что территория строки зарегистрирована непосредственно в данных учёта времени, а не определена по регистру территорий сотрудников. |
| Смена | `ЗНАЧЕНИЕ(Справочник.СменыРаботыСотрудников.ПустаяСсылка)` | Ссылка на справочник «СменыРаботыСотрудников» — смена, по которой планируется время, для сменных графиков. Пустая ссылка, если плановое время не связано со сменой. |
| ПереходящаяЧастьПредыдущейСмены | `ЛОЖЬ` | Булево — признак того, что плановое время строки является переходящей частью смены, начавшейся в предыдущие сутки и продолжавшейся на текущую дату. |
| ПереходящаяЧастьТекущейСмены | `ЛОЖЬ` | Булево — признак того, что плановое время строки является переходящей частью текущей смены, продолжающейся на следующие сутки. |
| Дни | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(5, 2))` | Число (дни) — количество дней по виду учёта времени в строке. Для строк по видам времени заполняется плановым значением, для посуточных строк графиков — значением дня при получении фактических данных. |
| Часы | `ВЫРАЗИТЬ(0 КАК ЧИСЛО(5, 2))` | Число (часы) — количество часов по виду учёта времени в строке. Для строк по видам времени заполняется плановым значением, для посуточных строк графиков — значением часа при получении фактических данных. |
| ДниПлан | `0` | Число (дни) — плановое количество дней по виду учёта времени на дату по данным графиков (индивидуального или общего). |
| ЧасыПлан | `0` | Число (часы) — плановое количество часов по виду учёта времени на дату по данным графиков (индивидуального или общего). |
| ДниНорма | `0` | Число (дни) — нормативное количество дней по графику нормы: норма рабочего времени сотрудника на дату. |
| ЧасыНорма | `0` | Число (часы) — нормативное количество часов по графику нормы: норма рабочего времени сотрудника на дату. |
