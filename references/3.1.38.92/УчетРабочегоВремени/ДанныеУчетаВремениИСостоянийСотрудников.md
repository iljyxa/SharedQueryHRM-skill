# ДанныеУчетаВремениИСостоянийСотрудников (ЗУП 3.1.38.92, подсистема УчетРабочегоВремени)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Посуточные данные учёта рабочего времени и состояний сотрудников подсистемы «УчетРабочегоВремени»: для каждого сотрудника и даты — дни и часы по видам использования рабочего времени, признак отклонения от плана, норма часов, смена и её переходящие части, а также организация, подразделение, должность, территория выполнения работ и условия труда. Фактические данные формируются из регистров накопления «ДанныеОперативногоУчетаРабочегоВремениСотрудников», «ДанныеТабельногоУчетаРабочегоВремениСотрудников», «ДанныеИндивидуальныхГрафиковСотрудников», «ВытесняемоеПлановоеВремяСотрудников» и «ДанныеСводногоУчетаРабочегоВремениСотрудников», плановые и нормативные показатели — по графикам из регистра сведений «ГрафикиРаботыПоВидамВремени» и справочника «ГрафикиРаботыСотрудников»; состояния сотрудников берутся из регистра сведений «СостоянияСотрудников», периоды работы с организацией, подразделением и должностью — из регистра сведений «ДанныеДляПодбораСотрудников». По каждому дню интервала возвращается строка состояния (вид времени определяется по соответствию состояния виду учёта времени) либо строка обычных данных учёта времени; отпускные дни, совпавшие с праздниками, отображаются как выходные. Требует входную временную таблицу сотрудников и формирует данные в пределах интервала ДатаНачала–ДатаОкончания с актуализацией на дату актуальности.

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| Сотрудник | `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)` | Ссылка на справочник «Сотрудники» — сотрудник, по которому формируются данные учёта времени и состояний. Состав сотрудников задаётся входной временной таблицей. |
| Дата | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — календарный день, к которому относятся данные учёта времени и состояний строки. Посуточная детализация формируется для каждого дня интервала ДатаНачала–ДатаОкончания. |
| ВидУчетаВремени | `ЗНАЧЕНИЕ(Справочник.ВидыИспользованияРабочегоВремени.ПустаяСсылка)` | Ссылка на справочник «ВидыИспользованияРабочегоВремени» — вид использования рабочего времени строки: рабочее время, выходные и праздники, отпуска, командировки, болезнь и другие. Для дней состояний вид определяется по соответствию состояния виду учёта времени. |
| Дни | `0` | Число (дни) — количество дней по виду учёта времени, приходящееся на дату. Целосменному виду времени соответствует один день, неполному дню — дробное значение. |
| Часы | `0` | Число (часы) — количество часов по виду учёта времени, приходящееся на дату (фактическое для фактических данных, плановое для плановых). Для неполных дней значение дробное, для целосменных видов соответствует продолжительности смены. |
| Отклонение | `ЛОЖЬ` | Булево — признак того, что время строки относится к отклонениям от планового времени: Истина, если по виду времени на дату отсутствуют плановые значения либо вид времени относится к целосменным отклонениям; Ложь — для плановых строк. |
| Организация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — организация (филиал), в которой числится сотрудник на дату, по периоду работы из регистра сведений «ДанныеДляПодбораСотрудников». |
| Подразделение | `ЗНАЧЕНИЕ(Справочник.ПодразделенияОрганизаций.ПустаяСсылка)` | Ссылка на справочник «ПодразделенияОрганизаций» — подразделение организации, в котором числится сотрудник на дату, по периоду работы. |
| Должность | `ЗНАЧЕНИЕ(Справочник.Должности.ПустаяСсылка)` | Ссылка на справочник «Должности» — должность сотрудника на дату по периоду работы; при ведении штатного расписания должность определяется по штатному расписанию. |
| НормаЧасов | `0` | Число (часы) — норма рабочего времени сотрудника на дату, рассчитанная по графику для видов времени, включаемых в норму. |
| Территория | `ЗНАЧЕНИЕ(Справочник.ТерриторииВыполненияРабот.ПустаяСсылка)` | Ссылка на справочник «ТерриторииВыполненияРабот» — территория выполнения работ на дату: по периодам действия территорий (регистр сведений «ТерриторииСотрудников») либо зарегистрированная в данных учёта времени. При отключённом получении территорий возвращается пустая ссылка. |
| УсловияТруда | `ЗНАЧЕНИЕ(Справочник.УсловияТруда.ПустаяСсылка)` | Ссылка на справочник «УсловияТруда» — условия труда, зарегистрированные для сотрудника на дату. При отключённом получении условий труда возвращается пустая ссылка. |
| Смена | `ЗНАЧЕНИЕ(Справочник.СменыРаботыСотрудников.ПустаяСсылка)` | Ссылка на справочник «СменыРаботыСотрудников» — смена, к которой относится время строки, для сменных графиков. Пустая ссылка, если время не связано со сменой. |
| ПереходящаяЧастьПредыдущейСмены | `ЛОЖЬ` | Булево — признак того, что время строки является переходящей частью смены, начавшейся в предыдущие сутки и продолжавшейся на текущую дату. |
| ПереходящаяЧастьТекущейСмены | `ЛОЖЬ` | Булево — признак того, что время строки является переходящей частью текущей смены, продолжающейся на следующие сутки. |
