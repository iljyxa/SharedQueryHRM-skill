# СвойстваСтатейФинансирования (ЗУП 3.1.38.92, подсистема ОтражениеЗарплатыВБухучете)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление СвойстваСтатейФинансирования подсистемы «ОтражениеЗарплатыВБухучете» — перечень статей финансирования заработной платы из справочника «СтатьиФинансированияЗарплата» со служебной колонкой НомерКолонки, принимающей постоянное значение 2. Формируется при включённой функциональной опции «РаботаВХозрасчетнойОрганизации» (для хозрасчётных организаций); в организациях бюджетного учёта используется отдельная реализация. Применяется как источник статей финансирования расходов на оплату труда при отражении зарплаты в бухгалтерском учёте.

## Параметры

Параметров нет.

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| СтатьяФинансирования | `ЗНАЧЕНИЕ(Справочник.СтатьиФинансированияЗарплата.ПустаяСсылка)` | Ссылка на справочник «СтатьиФинансированияЗарплата» — статья финансирования заработной платы. |
| НомерКолонки | `0` | Число — служебный номер колонки статьи финансирования; в запросе принимает постоянное значение 2 и используется при расположении статей расхода в отражении бухгалтерского учёта. |

## Заготовка текста представления

```bsl
ВЫБРАТЬ
	ЗНАЧЕНИЕ(Справочник.СтатьиФинансированияЗарплата.ПустаяСсылка) КАК СтатьяФинансирования,
	0 КАК НомерКолонки
ПОМЕСТИТЬ Представления_СвойстваСтатейФинансирования
```
