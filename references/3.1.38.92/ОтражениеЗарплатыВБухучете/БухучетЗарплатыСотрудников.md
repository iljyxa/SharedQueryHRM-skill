# БухучетЗарплатыСотрудников (ЗУП 3.1.38.92, подсистема ОтражениеЗарплатыВБухучете)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление БухучетЗарплатыСотрудников подсистемы «ОтражениеЗарплатыВБухучете» — действующие настройки бухгалтерского учёта заработной платы сотрудников: способ отражения зарплаты в бухучёте, статья финансирования и отношение к ЕНВД. Строится как срез последних записей регистра сведений «БухучетЗарплатыСотрудников» (периодичность — секунда, подчинён регистратору) по сотрудникам из входной временной таблицы-фильтра. Каждая запись результата содержит период действия настройки, документ-регистратор и служебные сведения среза. Используется для получения настроек бухучёта сотрудников при отражении начислений в бухгалтерском учёте.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: Истина — запрос строится с ВЫБРАТЬ РАЗРЕШЕННЫЕ, Ложь (по умолчанию) — без ограничения прав. |

| ДатаОкончания | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата окончания периода действия настройки бухгалтерского учёта сотрудника. |
