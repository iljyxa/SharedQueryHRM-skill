# СотрудникиПодлежащиеАттестации (ЗУП 3.1.38.92, подсистема АттестацииСотрудников)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление СотрудникиПодлежащиеАттестации подсистемы «АттестацииСотрудников» — сотрудники организаций, подлежащие очередной или внеочередной аттестации в заданном периоде: по виду аттестации с учётом ограничений по возрасту и минимальному сроку работы, отбора по должности/специальности и действующего графика аттестации. Строится на основе кадровых данных (механизм «СотрудникиОрганизации»), описаний видов аттестаций, специальностей физических лиц, сведений о проходящих и следующих аттестациях, внеочередных аттестациях и графиках. Дата аттестации — первая из дат внеочередной и следующей аттестации, попадающая в период; строка включается в результат, только если очередная или внеочередная дата не превышает окончание периода.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| НачалоПериода | Строка, Дата | Да | `&НачалоПериода` (выражение) | Задаёт начальную дату периода, за который определяется состав сотрудников, подлежащих аттестации. Обязательный, принимает выражение языка запросов (по умолчанию &НачалоПериода). |
| ОкончаниеПериода | Строка, Дата | Да | `&ОкончаниеПериода` (выражение) | Задаёт конечную дату периода: в результат включаются сотрудники, у которых очередная или внеочередная аттестация наступает не позднее этой даты. Обязательный, принимает выражение языка запросов (по умолчанию &ОкончаниеПериода). |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| Сотрудник | `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)` | Ссылка на справочник «Сотрудники» — сотрудник, подлежащий аттестации; ключевое поле набора. |
| Организация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — организация, к которой относится сотрудник (из кадровых данных). |
| Подразделение | `ЗНАЧЕНИЕ(Справочник.ПодразделенияОрганизаций.ПустаяСсылка)` | Ссылка на справочник «ПодразделенияОрганизаций» — подразделение, в котором числится сотрудник (из кадровых данных). |
| Должность | `ЗНАЧЕНИЕ(Справочник.Должности.ПустаяСсылка)` | Ссылка на справочник «Должности» — должность сотрудника в организации; используется для отбора по должностям вида аттестации. |
| ДатаПриема | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата приёма сотрудника на работу; используется для расчёта минимального срока работы до первой аттестации. |
| ДатаРождения | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата рождения сотрудника; используется для ограничений по возрасту, заданных видом аттестации. |
| Специальность | `ЗНАЧЕНИЕ(Справочник.КлассификаторСпециальностейПоОбразованию.ПустаяСсылка)` | Ссылка на справочник «КлассификаторСпециальностейПоОбразованию» — специальность сотрудника, по которой проверяется квалификация. |
| Категория | `ЗНАЧЕНИЕ(Справочник.РазрядыКатегорииДолжностей.ПустаяСсылка)` | Ссылка на справочник «РазрядыКатегорииДолжностей» — категория (разряд) должности, присвоенная по последней аттестации. |
| ДействуетПо | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — срок, до которого действует текущий результат аттестации по специальности; определяет предельный срок следующей проверки. |
| Дата | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата очередной аттестации сотрудника: внеочередная дата, если она назначена, иначе плановая следующая аттестация. |
| ДатаСледующейАттестации | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — плановая дата следующей (очередной) аттестации сотрудника по виду аттестации. |
| ДатаПоследнейАттестации | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата последней проведённой аттестации сотрудника по данному виду. |
| ДатаВнеочереднойАттестации | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата назначенной внеочередной аттестации сотрудника; пустая дата, если внеочередная аттестация не назначена. |
| ВидАттестации | `ЗНАЧЕНИЕ(Справочник.ВидыАттестацийСотрудников.ПустаяСсылка)` | Ссылка на справочник «ВидыАттестацийСотрудников» — вид аттестации, по которому сотрудник подлежит проверке. |
| ВключенВГрафикАттестации | `ЛОЖЬ` | Булево — признак включения сотрудника в действующий график аттестации по данному виду. |
| ГрафикАттестации | `ЗНАЧЕНИЕ(Документ.НаправлениеНаВнешнююАттестацию.ПустаяСсылка)` | Ссылка на документ — документ графика, в который включён сотрудник (приказ об аттестации либо направление на внешнюю аттестацию); пустая ссылка, если сотрудник не включён в график; композитный тип. |
