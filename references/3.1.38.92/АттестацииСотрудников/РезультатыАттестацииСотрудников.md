# РезультатыАттестацииСотрудников (ЗУП 3.1.38.92, подсистема АттестацииСотрудников)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление РезультатыАттестацииСотрудников подсистемы «АттестацииСотрудников» — результаты проведённых аттестаций сотрудников: по сотруднику, виду аттестации и дате проведения — решение аттестационной комиссии, результат подтверждения квалификации, приказ/направление на аттестацию и сведения документа о результатах. Источник — регистр сведений «РезультатыАттестацийСотрудников», соединённый со справочником «Сотрудники» (головная организация), справочником «ВидыАттестацийСотрудников» и строками документа «РезультатыАттестацииСотрудников» (специальность, категория, должность, документ о квалификации); по регистратору присоединяется внеочередная аттестация. Период, за который выводятся результаты, задаётся параметрами запроса отчёта (обязательные границы периода).

## Параметры

Параметров нет.

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| Сотрудник | `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)` | Ссылка на справочник «Сотрудники» — сотрудник, прошедший аттестацию; ключевое поле строки результата. |
| Организация | `ЗНАЧЕНИЕ(Справочник.Организации.ПустаяСсылка)` | Ссылка на справочник «Организации» — головная организация, к которой относится сотрудник (реквизит «ГоловнаяОрганизация» справочника «Сотрудники»). |
| ВидАттестации | `ЗНАЧЕНИЕ(Справочник.ВидыАттестацийСотрудников.ПустаяСсылка)` | Ссылка на справочник «ВидыАттестацийСотрудников» — вид проведённой аттестации, определяющий тип, периодичность и условия процедуры. |
| ЭтоВнешняяАттестация | `ЛОЖЬ` | Булево — признак того, что вид аттестации является внешней (проводится аттестационной организацией); берётся из реквизита вида аттестации. |
| ДатаВнеочереднойАттестации | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата внеочередной аттестации сотрудника из регистра сведений «ВнеочередныеАттестацииСотрудников» по регистратору; пустая дата, если внеочередной аттестации не было. |
| ДатаАттестации | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата (период) проведения аттестации по регистру сведений «РезультатыАттестацийСотрудников». |
| РешениеКомиссии | `ЗНАЧЕНИЕ(Справочник.РешенияАттестационныхКомиссий.ПустаяСсылка)` | Ссылка на справочник «РешенияАттестационныхКомиссий» — решение аттестационной комиссии по итогам аттестации (соответствует/не соответствует занимаемой должности и т.п.). |
| РезультатАттестации | `ЗНАЧЕНИЕ(Перечисление.РезультатыПодтвержденияКвалификацииПоСпециальности.ПустаяСсылка)` | Ссылка на перечисление «РезультатыПодтвержденияКвалификацииПоСпециальности» — результат подтверждения (неподтверждения) квалификации по специальности. |
| Регистратор | `ЗНАЧЕНИЕ(Документ.РезультатыАттестацииСотрудников.ПустаяСсылка)` | Ссылка на документ «РезультатыАттестацииСотрудников» — документ, зарегистрировавший результат аттестации (регистратор записи регистра сведений). |
| ПриказОбАттестации | `ЗНАЧЕНИЕ(Документ.НаправлениеНаВнешнююАттестацию.ПустаяСсылка)` | Ссылка на документ — приказ или направление, на основании которого проведена аттестация: документ «ПриказОбАттестацииСотрудников» либо (для внешней аттестации) «НаправлениеНаВнешнююАттестацию»; композитный тип. |
| Номер | `ВЫРАЗИТЬ("" КАК СТРОКА(11))` | Строка — номер документа «РезультатыАттестацииСотрудников», в котором зафиксирован результат. |
| Дата | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата документа «РезультатыАттестацииСотрудников». |
| Специальность | `ЗНАЧЕНИЕ(Справочник.КлассификаторСпециальностейПоОбразованию.ПустаяСсылка)` | Ссылка на справочник «КлассификаторСпециальностейПоОбразованию» — специальность, по которой проведена аттестация (из строки документа результатов). |
| Категория | `ЗНАЧЕНИЕ(Справочник.РазрядыКатегорииДолжностей.ПустаяСсылка)` | Ссылка на справочник «РазрядыКатегорииДолжностей» — категория (разряд) должности, присвоенная по результату аттестации. |
| Должность | `ЗНАЧЕНИЕ(Справочник.Должности.ПустаяСсылка)` | Ссылка на справочник «Должности» — должность, по которой проводилась аттестация сотрудника. |
| СерияДокумента | `ВЫРАЗИТЬ("" КАК СТРОКА(14))` | Строка — серия документа, удостоверяющего результат (подтверждающего квалификацию). |
| НомерДокумента | `ВЫРАЗИТЬ("" КАК СТРОКА(14))` | Строка — номер документа, подтверждающего результат аттестации. |
| ДатаДокумента | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата документа, подтверждающего результат аттестации. |
| Основание | `""` | Строка — текстовое основание результата аттестации, указанное в документе. |
