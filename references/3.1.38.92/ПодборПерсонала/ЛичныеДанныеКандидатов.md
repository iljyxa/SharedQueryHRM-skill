# ЛичныеДанныеКандидатов (ЗУП 3.1.38.92, подсистема ПодборПерсонала)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление ЛичныеДанныеКандидатов подсистемы «ПодборПерсонала» — анкетные и личные сведения кандидатов из справочника «ЛичныеДанныеКандидатов»: ФИО, пол, дата и место рождения, семейное положение, гражданство, возраст, контакты (email, адрес, телефон), связанное физическое лицо, владение языками и образование (основное и два дополнительных по приоритету вида образования). Формируется соединением справочника с контактной информацией кандидата, регистром сведений «ФизическиеЛицаКандидатов», сведениями о знании языков и образования; возраст рассчитывается на текущую дату сеанса. Требует входной временной таблицы-фильтра с полем ЛичныеДанныеКандидата (обязательная).

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: Истина — запрос строится с ВЫБРАТЬ (РАЗЛИЧНЫЕ) РАЗРЕШЕННЫЕ, Ложь (по умолчанию) — без ограничения прав. |
