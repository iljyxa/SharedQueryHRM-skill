# СведенияОКандидатах (ЗУП 3.1.38.92, подсистема ПодборПерсонала)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление СведенияОКандидатах подсистемы «ПодборПерсонала» — основные сведения о кандидатах: реквизиты кандидата (вакансия, позиция штатного расписания, подразделение, ожидаемый доход и его валюта/периодичность, источник информации, адрес резюме, «о себе», ответственный, рейтинги, состояние согласования и причина отклонения), личные данные (ФИО, контакты, возраст, образование, языки), сопроводительное письмо, текущий этап работы с кандидатом и фотография. Источник — справочник «Кандидаты» с присоединением личных данных кандидатов, откликов по источникам информации, регистра сведений «ТекущиеЭтапыРаботыСКандидатами» и вложенных файлов с фотографией; профиль должности берётся из вакансии. Требует входной временной таблицы-фильтра с полем Кандидат (обязательная).
