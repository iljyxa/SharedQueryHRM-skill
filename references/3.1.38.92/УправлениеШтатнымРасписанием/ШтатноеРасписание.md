# ШтатноеРасписание (ЗУП 3.1.38.92, подсистема УправлениеШтатнымРасписанием)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: не обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: есть

Представление ШтатноеРасписание подсистемы «УправлениеШтатнымРасписанием» — сведения о позициях штатного расписания на дату актуальности: наименования, организация, подразделение, должность, график работы, тарифная сетка и разряд/категория, количество ставок, показатели оплаты труда (оклад/тариф, ФОТ, районный коэффициент, северная надбавка, надбавка за вредность), характеристики для досрочного пенсионного обеспечения, класс условий труда и занятость позиции. Формируется по справочнику «ШтатноеРасписание» с учётом истории изменения штатного расписания (при её использовании) на заданную дату; при параметре ВключатьНачисления дополнительно присоединяются начисления и показатели по позициям. Закрытые позиции исключаются по умолчанию. Используется в отчётах по штатной численности, планированию ФОТ и анализу занятости.
