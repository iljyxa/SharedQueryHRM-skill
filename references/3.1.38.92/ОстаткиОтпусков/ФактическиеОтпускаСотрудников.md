# ФактическиеОтпускаСотрудников (ЗУП 3.1.38.92, подсистема ОстаткиОтпусков)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: да
- **Таблица фильтра**: обязательна
- **Отборы по полям**: нет
- **Программный интерфейс**: есть

Представление ФактическиеОтпускаСотрудников подсистемы «ОстаткиОтпусков» — фактические предоставленные сотрудникам ежегодные отпуска за период по данным регистра накопления «ФактическиеОтпуска». Строка набора образуется по сотруднику, виду отпуска и датам отпуска: количество дней (сумма по записям регистра, пересекающимся с периодом фильтра), признак компенсации, рабочий период, за который предоставлен отпуск, основание и документ-регистратор. Записи, сторнированные обратными записями другого регистратора, а также с нулевым суммарным количеством из результата исключаются. Требует входной временной таблицы-фильтра с полями Сотрудник, НачалоПериода, ОкончаниеПериода. Используется в расчёте и анализе остатков отпусков.

## Параметры

| Имя | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| ТолькоРазрешенные | Булево, Строка | Нет | `ЛОЖЬ` | Разрешает выборку только разрешённых по правам доступа записей: Истина — запрос строится с ВЫБРАТЬ РАЗРЕШЕННЫЕ, Ложь (по умолчанию) — без ограничения прав. |

## Поля

| Имя | Выражение | Описание |
|---|---|---|
| Сотрудник | `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)` | Ссылка на справочник «Сотрудники» — сотрудник, которому предоставлен фактический отпуск; ключевое поле набора, по нему выполняется связка с таблицей-фильтром. |
| ВидЕжегодногоОтпуска | `ЗНАЧЕНИЕ(Справочник.ВидыОтпусков.ПустаяСсылка)` | Ссылка на справочник «ВидыОтпусков» — вид ежегодного отпуска (основной, дополнительный и т.п.); способ расчёта вида определяет, в календарных или рабочих днях исчисляется количество дней. |
| ДатаНачала | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата начала фактического отпуска. |
| ДатаОкончания | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата окончания фактического отпуска; запись включается, если отпуск пересекается с периодом фильтра. |
| КоличествоДней | `0` | Число (дни) — количество дней фактического отпуска (календарных или рабочих в зависимости от вида), суммарно по записям регистра; записи с нулевой суммой исключаются. |
| ЭтоКомпенсация | `ЛОЖЬ` | Булево — признак того, что запись отражает компенсацию неиспользованного отпуска (соответствует ресурсу «Компенсация» регистра накопления). |
| Регистратор | `ЗНАЧЕНИЕ(Документ.СторнированиеНачислений.ПустаяСсылка)` | Ссылка на документ — документ-регистратор, которым данные о фактическом отпуске внесены в регистр накопления «ФактическиеОтпуска». |
| ВРабочихДнях | `ЛОЖЬ` | Булево — признак того, что вид отпуска рассчитывается в рабочих днях (СпособРасчетаОтпуска = ВРабочихДнях); иначе отпуск календарный. |
| РабочийПериодС | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата начала рабочего периода (рабочего года), за который предоставлен отпуск. |
| РабочийПериодПо | `ДАТАВРЕМЯ(1, 1, 1)` | Дата — дата окончания рабочего периода (рабочего года), за который предоставлен отпуск. |
| Основание | `ВЫРАЗИТЬ("" КАК СТРОКА(1024))` | Строка — основание предоставления отпуска (текст, до 1024 символов). |

## Заготовка текста представления

```bsl
ВЫБРАТЬ
	ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка) КАК Сотрудник,
	ЗНАЧЕНИЕ(Справочник.ВидыОтпусков.ПустаяСсылка) КАК ВидЕжегодногоОтпуска,
	ДАТАВРЕМЯ(1, 1, 1) КАК ДатаНачала,
	ДАТАВРЕМЯ(1, 1, 1) КАК ДатаОкончания,
	0 КАК КоличествоДней  // … и другие поля из таблицы выше (всего 11)
ПОМЕСТИТЬ Представления_ФактическиеОтпускаСотрудников
ИЗ
	ВТФильтр КАК ВТФильтр
```

## Программный интерфейс

Шаблон кода на встроенном языке; правила подстановки плейсхолдеров `<…>` — в `references/программный-интерфейс.md`.

```bsl
ОписательВТ = ОстаткиОтпусков.ОписательВременныхТаблицДляСоздатьВТФактическиеОтпускаСотрудников(
	МенеджерВременныхТаблиц,
	"<Фильтр>",
	"Сотрудник,НачалоПериода,ОкончаниеПериода",
	"ВТФактическиеОтпускаСотрудников");

ОстаткиОтпусков.СоздатьВТФактическиеОтпускаСотрудников(
	ОписательВТ,
	<ТолькоРазрешенные>);
```
