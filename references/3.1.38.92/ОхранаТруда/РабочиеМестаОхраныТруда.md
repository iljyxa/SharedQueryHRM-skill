# РабочиеМестаОхраныТруда (ЗУП 3.1.38.92, подсистема ОхранаТруда)

Сгенерировано из `data/` скриптом `scripts/build_references.py`, вручную не редактируется. Синтаксис и правила применения — `references/механизм-представлений.md`.

- **Основное**: нет
- **Таблица фильтра**: не используется
- **Отборы по полям**: нет
- **Программный интерфейс**: нет

Представление РабочиеМестаОхраныТруда подсистемы «ОхранаТруда» — сведения о рабочих местах по охране труда из справочника «РабочиеМестаОхраныТруда»: номер, организация-владелец, подразделение, должность, характеристики для досрочного пенсионного обеспечения (взимание взносов, основание досрочной пенсии, особые условия труда ПФР, позиция списка), надбавка за вредность и дополнительный отпуск. Выборка LEFT JOIN к регистру сведений «НастройкиОхраныТруда»: возвращаются только рабочие места организаций, не настроивших собственное ведение рабочих мест (настройка «ИспользоватьРабочиеМестаОхраныТруда» не включена); исключаются группы, помеченные на удаление элементы и рабочие места в архиве. Параметры-признаки раздела охраны труда (инструктажи, обучение, медосмотры, несчастные случаи, СОУТ, СИЗ) дополнительно ограничивают выборку рабочими местами организаций с включённым соответствующим разделом.
